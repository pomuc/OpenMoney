# Участие в проекте

Спасибо за интерес к OpenMoney.

## Как внести изменение

1. Сделайте fork / ветку от актуального `main`.
2. Держите изменения узкими: исправление, доработка SDK, документация, тесты.
3. Убедитесь, что `dotnet build OpenMoney.sln -c Release` проходит без ошибок.
4. Откройте pull request с понятным описанием «зачем».

## Требования к безопасности

PR с реальными ключами, сертификатами, прод‑строками подключения или персональными данными **не принимаются**.

В примерах используйте только плейсхолдеры:

```
YOUR_API_KEY
YOUR_CLIENT_ID
YOUR_CLIENT_SECRET
YOUR_DATABASE_URL
```

## Стиль

- Небольшие, ревьюируемые PR.
- Не меняйте архитектуру без обсуждения.
- В SDK: nullable включён, сетевые методы принимают `CancellationToken`, секреты не пишутся в логи и исключения.

## Отказ от ответственности

Это неофициальные community‑проекты. Они не аффилированы с Т‑Банком, банком «Точка», ВТБ, CloudPayments, Inwizo и другими провайдерами.
