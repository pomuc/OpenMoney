# Политика безопасности

## Как сообщить об уязвимости

**Не создавайте** публичный GitHub Issue по вопросам безопасности.

Сообщайте приватно мейнтейнеру репозитория (предпочтительно GitHub Security Advisories после публикации репозитория).

## Правила для контрибьюторов и примеров

- Не коммитьте реальные credentials, сертификаты и прод‑connection strings.
- Не используйте боевые банковские/платёжные ключи в примерах и тестах.
- Не включайте персональные данные клиентов (ФИО, ИНН, телефоны, email, счета, карты).
- Pull request с секретами или PII будет отклонён.

## Область применения

Проекты OpenMoney работают с банковскими и платёжными API. Ошибка конфигурации может привести к реальному движению денег. Песочницу и прод‑ключи храните раздельно; любые ключи, которые когда‑либо могли попасть в историю репозитория или переписку, перед использованием в бою нужно ротировать.
